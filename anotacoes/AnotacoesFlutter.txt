Comando para criar um projeto em flutter: 
	-> flutter create todo_list_provider --platforms=ios,android --org=br.com.flutterdicas.todolistproviderfelipe
	
Comando para ver a versão do flutter: 
	-> flutter --version
	 
O arquivo pubspec.yaml onde é descrito algumas informações do app.
Ele usa esse arquivo para colocar as dependencias. 
Obs.: Tem que estar identado. 

=> O provider adicionado como dependencias, é usado para gerenciar os estados e dependencias.
=>	O uuid: vai ser usado para criar identificares, ou seja id que serão utilizados na aplicação.
=>	O flutter_secure_storage: vai ser usado para manter o estado do aplicativo, ou seja manter os dados, mesma
	que seja encerrada a aplicação;
=>	O flutter_localizations: vai ser usado para traduzir o calendário para o portugês do brasil;

Exemplo: 
dependencies:
  provider: ^6.0.5
  uuid: ^3.0.7 
  flutter_secure_storage: ^8.0.0
  flutter_localizations:
    sdk: ^3.0.7
  flutter:
    sdk: flutter
Comando para atualizar as dependencias é 
 ->	flutter pub get.

Vídeo 6: Anotações

Nesse vídeo ele começa explicando que vai criar um 
modelo para ficar mais fácil. 

Logo ele cria uma pasta shared\models dentro da lib e o arquivo 
todo_model.dart.	

OBSERVAÇÃO: ELE VAI FAZER O CÓDIGO EM INGLÊS, MAS O 
VISUAL PARA O USUÁRIO SERÁ EM PORTUGÊS.

Ele programa todo o todo_model, para usar no todo_screen. 
Com o código abaixo: 
import 'package:uuid/uuid.dart';

class TodoModel {
  final String id;
  final String title;
  final String? description; /*? significa que pode ser nulo*/
  final DateTime date;

  TodoModel({
    String? cId,
    required this.title,
    this.description, //Sem o required, não é obrigatório.
    DateTime? cDate,
  }) : id = cId ?? const Uuid().v4(),
       date = cDate ?? DateTime.now();
}
Após isso ele cria a pasta widgets, usando o model, 
para cada elemento que será utilizado. 
Como título, checkbox, descrição e data.
